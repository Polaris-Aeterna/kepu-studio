# 把 taste-skill 迁移到动画视频帧

来源：taste-skill（tasteskill v2，`design-taste-frontend`：SKILL.md 与 references/colour、type、layout、tells、critique、motion、scenes）。装了 taste-skill 的话，细节以它为准；这一份是《ETH 之墙》把它迁移到视频帧时的结论。
它为网页而写，研究对象是 247 个画廊网站。下面只留下对 **1920×1080、30fps、每期约 30 分钟、整季约 3 小时的讲解视频**仍然成立的部分（例子来自《ETH 之墙》，像素引擎同样适用）。每条规则后面都写了在 Manim 里的落地办法。

> 一句话总结：**一个底色、一个墨色、一个强调色；两到三种字号，彼此差距拉大；结构靠色块和留白，不靠细线和装饰；整期只有一个“签名动作”，其余动作都安静。**
> 去掉装饰之后，留下的空要用**内容本身**补上：把主物体放大、把这个题目自己的东西（子句、变量、子句图、比特）当成画面材料，而不是换上另一种装饰。

---

## 1. 想法来自题材本身

taste-skill 最核心的一条：在盲测里，赢的页面都用了**从题材本身取出的概念**，输的页面只有“好看的构图 + 品类默认套路”。迁移到视频，就是给每期写出下面这句话：

> 在这一期里，**[SAT / ETH 自己的东西]** 变成 **[这个画风特有的视觉装置]**。

例如：“子句图的**切口比特** 变成 Mini Metro 里**过河的桥**：桥越少，切得越便宜。”

**竞品测试**：把这句话里的题材换成另一个科普题目（比如“傅里叶变换”），如果句子仍然成立，说明这只是一层皮，还不是一个想法。

**Manim 落地**：每个画风在 `concepts/*.py` 文件头写一行 `IDEA = "..."`；每个组件（变量、子句、边、切割）都必须在这个画风的世界观里有一个对应物，而不是在画风背景上贴一个通用的 `CNF()`。

## 2. 配色：角色与比例

| 角色 | 网页里 | 视频里 | 占比 |
|---|---|---|---|
| `bg` 底色 | 页面底 | 整个画面的底 | **70–90%**（单帧里的面积） |
| `surface` | 面板 | 卡片、图形填充面，与 bg 只差 2–6 个明度点 | 0–20% |
| `ink` | 正文 | 文字、主要图形、线条 | 余下大部分 |
| `muted` | 次要文字 | 注释、未激活的节点；在 bg 上对比度仍须 ≥ 4.5:1 | 少量 |
| `accent` | 唯一按钮 | **这一帧的唯一焦点**：被满足的文字、被切断的边、当前步骤 | **< 5%** |

规则：

- **强调色每帧最多出现在两处**：一个焦点，最多再加一个与它呼应的细节。出现在五个地方，它就不再意味着“看这里”。标题用 ink，不用 accent。
- **真/假不能各占一个高饱和色。** 默认风格里“青绿 = 真、红 = 假”，满屏都是彩色。改为：真 = accent 实心，假 = ink 或 muted 空心（或者 ink 与 bg 反相）。只有当 T/F 正是这一帧的主题时，才让 F 也有颜色。
- **区分面靠明度台阶，不靠描边或投影。** 面板 = `surface` 实心填充，`stroke_width=0`。
- **整块色场**是最强的配色动作：一段内容整屏换底色（比如定理时刻整屏翻成 ink 底、bg 色字），硬切换，不渐变。
- **暗底**：bg 用带一点色相的深色，不用 `#000`；ink 用柔和的浅色，不用 `#fff`（除非是刻意的黑白二色，比如 EVA 风）。暗底上字重降一级。
- **禁用的配色族**：紫色和靛蓝；奶油黄底 + 赤陶/锈红/陶土色（AI 助手的招牌配色）；霓虹色 + 发光；渐变（包括曲线、文字和背景上的渐变）。
- 想要“温暖”，就用低饱和的石色/骨色/油灰色底（饱和度 < 15%），或者深绿、深棕、牛血红作 ink，或者一整块坚定的暖色场。温暖不等于米色。
- **Manim 落地**：每个风格文件开头定义 `BG / SURFACE / INK / MUTED / ACCENT (/ ACCENT_INK)`，所有颜色只引用这五六个常量，代码里不出现裸 hex。用 `default_camera_config = dict(background_color=BG)`。不用 `set_color_by_gradient`、不用 `glow`、不用透明度叠出的“光晕”。

## 3. 字体层级

- **两到三个字号干活，彼此差距大**：一个很大（展示级），一个正文，一个小注，中间不留过渡档。网页研究中标题 ÷ 正文的中位数是 4.3，顶级站点更大。
  视频里换算（1080p，Manim 的 font_size）：展示 **120–200**，正文 **36–44**，小注 **26–30**。全片不超过五档。
- **一种字族是常态，最多两种**：一种管标题，另一种管其余一切，永不互换。公式的 LaTeX Computer Modern 不算第三种。
- 大字收紧字距、行距 0.9–1.05。Manim 的 `Text` 没有 tracking 参数，靠字体本身（Condensed、宋体 Black）、`lsh` 行距，以及对整个 mobject 做 `stretch` 来控制。
- **不用小号大写宽字距标签、不用等宽字体、不用 eyebrow（标题上方的小标签）。** 信息直接写进标题或第一句话。
- 不给标题里的某个词单独上色或加斜体（“styled accent word”）。强调靠词语本身；需要指物时，用 accent 填充对象，而不是给文字上色。
- 暗底上的浅色字看起来更重，要降一级字重。
- **Manim 落地**：中文可用 PingFang SC（ULTRALIGHT–SEMIBOLD）、Songti SC（LIGHT / NORMAL / BOLD / HEAVY）、Noto Serif/Sans CJK SC；西文和数字可用 Avenir Next（含 Condensed HEAVY）、Helvetica Neue、Futura、Didot、Optima、Baskerville、DIN Condensed。实测 `"Futura Condensed ExtraBold"`、`"Helvetica Neue Condensed Black"` 这类家族名在 Pango 里解析不到，会回退。

## 4. 版面与留白

- **一个画框、两到三条对齐线。** 定义 1–2 条文字锚线（比如 x = −6.2 和 x = −1.0），整期所有文字块都挂在这几条线上。一帧里出现六个不同的左边缘，就是“一样一样摆上去的”。
- **偏离中心胜过居中。** 标题放左侧三分之一处，右侧放它的图形；居中只留给一个时刻（例如定理宣布）。
- **一帧只有一个主体。** 眯眼看，画面应该只剩两三团大小差别明显的块。
- **空白要有东西“收住”它。** 左边放字、右边就得有图；不能让一半屏幕空着。没有东西收住的空白就是破洞，解决办法是**把主体放大**，而不是加装饰。
- 相关的东西靠近，不相关的离远；标题上方的距离至少是下方的两倍。
- 相邻两个段落的构图不能相同：分屏 → 满屏图 → 大字陈述 → 表格……按 beat 轮换。
- **刻意打破一次系统。** 全片建立规则之后，在一个关键时刻打破它（比如全程不用 accent 大面积，到“ETH 被证伪”那一刻整屏翻成 accent 色场）。
- **Manim 落地**：安全区 x ∈ [−6.6, 6.6]；字幕条另行规定。每个风格定义 `ANCHOR_X` 常量，标题、正文、注释都用 `.align_to(ANCHOR_X 处的点, LEFT)` 或 `move_to` 对齐。

## 5. 装饰禁令（tells.md 的“AI 味”清单 → 视频版）

| 禁用 | 在视频里通常长什么样 | 改成 |
|---|---|---|
| 渐变 | 渐变背景、渐变曲线、彩虹色 | 纯色；分层靠明度台阶 |
| 霓虹 + 发光 | 暗底 + 青/洋红描边 + 外发光 | 实心填充；深度靠更亮的面 |
| 紫色 / 靛蓝 | 默认的“科技紫” | 从画风出处取色 |
| 软投影 | 卡片下面的灰色阴影 | 面板与底色差一个明度台阶 |
| 到处是 1px 细线框 | 每个元素外面套一个细描边方框、网格、十字准星、裁切标记 | 留白、整块填色、需要“条”时用 ≥ 4px 的粗条 |
| 等宽小标签 | `// STEP_01`、`[SYS] ...`、坐标、时间戳、版本号 | 正文字体、正常字号的普通句子 |
| 编号 01 / 02 / 03 | 角落里的 “01”“PHASE 02” | 顺序靠位置、大小或文字本身表达 |
| 奶油底 + 赤陶色 | `#F5EFE6` 底 + `#C96442` | 石色/骨色底 + 深墨，或者一整块坚定的色场 |
| 小号大写宽字距标签 | `C L A U S E  G R A P H` | 句子式写法（sentence case），正常字号 |
| 一行三张一样的图标卡片 | 三个圆角卡片，每张顶上一个图标 | 一个大图形 + 一行字 |
| 玻璃/毛玻璃 | 半透明模糊面板 | 不透明的 surface |
| emoji、装饰形状、漂浮光斑 | 背景里漂浮的点、粒子 | 删掉 |
| 标题里单独上色的一个词 | “SAT 是**什么**” | 同一字体、同一颜色 |

最后一条（`tells.md` §8）：去掉装饰之后**不能只剩空**。“礼貌的空页面”本身也是一种 tell。补位的东西按优先级排：把主体放大 → 内容写全 → 用这个题目自己的图形（子句图、真值表、增长曲线）→ 整块色场。

## 6. 动效：一个签名动作，其余安静

- **每期一个签名动作**（每个画风一个，贯穿 6 期）：观众一小时后还能描述出来的那一下。例如 Mini Metro 风是“画线”（线路从车站长出来）；P5 风是“斜切转场”。只有它可以“响”。
- **其余入场都要编排，但要安静**：按阅读顺序（标题 → 文字 → 图），间隔 60–90ms，上移 0.15–0.3 个单位并淡入，只播一次。不同内容用不同的方式：列表逐行进，图从遮罩里打开，数字滚动一次。**不要每个元素都用同一个 `FadeIn(shift=UP)`。**
- **缓动曲线**：入场用 ease-out（快起慢停），两点之间的移动用 ease-in-out，离场用短的 ease-in，时长约为入场的 60–70%。**禁止回弹和弹性曲线。**
- **时长**：小移动 0.3–0.45 s；揭示和逐行上升 0.6–1.0 s；画面打开和擦除 1.1–1.6 s。
- **禁止没有意义的无限循环**：脉动的点、漂浮的形状、闪烁的文字、旋转的徽章。
- **文字在被读的时候，不能有东西从它上面经过。** 变暗最多到 40%，模糊不超过 8px，而且必须在稳定后消失。
- 首帧可读：每个 beat 开始时，最多 1.2 秒内主体就要到位，不能让观众盯着空屏等字出现。
- **Manim 落地**：

```python
EASE_OUT   = lambda t: 1 - (1 - t) ** 5          # quint out: 入场
EASE_EXPO  = lambda t: 1 if t == 1 else 1 - 2 ** (-10 * t)  # 长揭示
EASE_INOUT = smooth                               # 两点间移动 (manimlib.utils.rate_functions.smooth)
EASE_EXIT  = lambda t: t ** 3                     # 离场
# 逐行入场：LaggedStart(*[FadeIn(l, shift=0.2*UP, rate_func=EASE_OUT) for l in lines], lag_ratio=0.15, run_time=0.8)
```

  不用 `there_and_back`、`wiggle`、`Indicate` 这一类的“抖一下”作为常规强调；改用 accent 填充对象，或者把对象放大到 1.08 倍再停住。

## 7. “场景”：每期两三个大时刻

`scenes.md` 里的滚动场景，对应视频里一段**整屏的大动作**：镜头穿过一个空间、一张图从窗口扩到满屏、文字横穿舞台。规则：

- 每期两到三个，来自不同类型，中间隔一段安静的内容。
- 每个持续 1–4 个 beat，每个 beat 都要有新东西，不靠拉长时间凑。
- 在它的停驻点必须可读。
- Manim 里用 `self.camera.frame` 的移动、缩放来做，或者用遮罩 `Rectangle` 做窗口打开。

## 8. 自我批评（critique.md → 视频帧）

对每张概念帧按下面五项检查（原文共 14 项，挑出与单帧相关的），写成固定格式：

1. **一秒、再五秒**：一眼看到的是什么？只能有一个答案。五秒后能不能说出这是哪一期、讲什么？
2. **眯眼**：是否只剩两三团大小差异明显的块？
3. **盖住标题**：这一帧换成别的科普题目还成立吗？成立，就说明画风没有和题材结合。
4. **边缘**：数一数左边缘有几个不同的 x 位置，应该是两到三个。
5. **颜色**：说出各色的比例；accent 出现了几处？
6. **空间**：有没有没被收住的空白（破洞）？有没有元素挤在一侧？
7. **碰撞**：有没有东西压在文字上、贴着画框边？

评分权重沿用原文：设计 40%、可用性（可读、清楚）30%、创意 20%、内容 10%。原文的封顶规则也照搬：只要出现渐变、发光、细线装饰、编号、等宽标签，总分封顶 6.5。第一次给自己打 9 分时，换成“不是你做的”评委重打一遍。

## 9. 视频特有、网页规则里没有的

- **3 小时可持续性**：长时间看，高饱和大色场会让眼睛疲劳。主体时间用低饱和 bg，高饱和色场只留给“时刻”（标题卡、定理、转折）。浅底在大屏、暗房间里会刺眼；暗底更耐看，但要防止画面发闷。
- **复杂公式与图的容量**：画风必须能装下 6×6 的矩阵、十几个节点的图、三行公式。画风装饰越多，内容区就越小；评分时单独看这一项。
- **字幕条**是画面的一部分：它的字体、底色、位置要属于这个画风，不能是外挂的黑条。
- **公式**：Computer Modern 与画风字体的气质要协调（宋体风搭 CM 很自然；几何无衬线风格可以把公式里的数字换成 `\mathsf`）。
