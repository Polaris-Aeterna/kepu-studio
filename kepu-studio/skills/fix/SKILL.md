# 作者报问题时

这套流程来自《地基之下》的 fix-report，原则是：
- **先确认是哪一处，再动手。**
- **作者的耳朵和眼睛定标准。**
- **能强制就别检测。**
- **改完拿成片核对**，给作者能直接听、直接看的东西。

## 1. 定位（不花钱）

- **时间换算成句子**：去成片的 srt（`output/epNN/*.srt`）里找。也可以用 `beats.json` 加 `.timeline.json` 算出是哪个 beat、哪个字。作者没说是哪个版本（像素版、Manim 版、英文版）的，就问清楚，或者每个版本都查。
- **读音问题**：
  1. 找出这句话里**每一处**同一个字，全部列出来。
  2. 作者只说了一处的，**问清是哪一处、要念什么**。教训：同一句里两个“数”读音不同（一直数〔shǔ〕下去 / 有没有一种“数〔shù〕”），当时先改错了一处。作者已经说得清清楚楚的，就不用再问。
  3. 用 `./kepu pron "整句原文"` 看现在的决定，以及当时发给模型的文字。
- **画面问题**：先找到场景和帧。
  - 像素引擎：`python -m pixel.occlusion epNN --json` 和 `occlusion_sheet`。
  - anime 引擎：用 `FRAME=1` 渲染那一帧。

## 2. 读音问题

1. **定读音**：以作者为准，不一定是词典读音。拿不准的，给 2–3 个候选的试听让作者选。
2. **落到文件里**（只增改，不删别人的条目）：
   - 只管这一处：在稿子的读法一侧标 `字〔读音〕`。
   - 这个词以后都这么念：`./kepu lexicon add "…〔…〕…"`，再用 `./kepu lint script/episodes/*.md` 查有没有误伤别的句子。还要查已经发布的各期里有没有同样的词，要不要一起重录。
   - 替身字念歪了：`./kepu earcheck ingest` 会把它记为不可用，下次自动换一个。新替身字第一次用，一定先单独听一遍。
3. **重录**：`./kepu voice 稿子 --only NN`。这一步花钱：说清字数，作者让修就算批准。
4. **重做画面**：只重渲受影响的场景，然后重拼。
   - anime 引擎：`engine/render.sh` 加 `assemble.py`。
   - pixel 引擎：`build --only` 加整集拼接。
5. **核对**：
   - `./kepu gate 稿子 --stage voice --stage release`。
   - 确认新录音真的在成片里：取成片那一段和新录音做一次互相关，或者直接截出那 3 秒来听。教训：成片核对漏掉过一个缓存目录。
6. **给作者听**：截出改过的那一句，新旧对照、带编号，用 SendUserFile 发过去，并写清“第几句应该念什么”。
7. **记录**：写进 `LESSONS.md`（事、根子、以后怎么做），再交给 `kepu-studio:retro`。

## 3. 画面问题（遮挡、出框、空白、字幕）

1. 只改分镜或场景代码的布局：
   - 挪位置；
   - 收紧卡片；
   - 上下堆叠的标签间距要大于字高；
   - 该消失的东西在已有的动作里 hide 掉。
   **不改旁白文字**，不改共享引擎。
2. 像素引擎：先过 `python -m pixel.build epNN --check`，再看 occlusion。有意的叠放（印章、删除线），看过联系表后加进白名单。
3. 渲染改好的那一帧发给作者确认，然后重做整集。
4. 字幕切分的问题：
   - anime 引擎：`engine/resrt.py` 可以不重渲、只重导 srt。
   - 烧录在画面里的字幕必须重渲。

## 4. 汇报

中文，简短，写清这几件事：
- 改了哪一处；
- 现在念什么、长什么样；
- 哪几集重做了；
- 作者要做什么，例如在 B 站换视频文件。

附上试听或截图。
