# 立项：新系列 / 新一期

## 新系列

1. **选引擎**。先问作者，或者按下面的经验推荐：
   - **anime**：ManimGL 动漫标题卡风，例如 EVA、女神异闻录、NieR。适合理论和证明，对标 3B1B。需要装 ManimGL 和 LaTeX。
   - **pixel**：像素 RPG 风。适合长系列、面向初学者。纯 Python，同学的电脑上最好装。
   - **none**：自己的渲染器，只用 kepu 的稿子、读音、配音、讲义、审稿和发布这几部分。
2. **建项目**：
   ```bash
   python3 "${CLAUDE_PLUGIN_ROOT}/toolkit/kepu_run.py" init <目录> --engine anime --name "系列名"
   cd <目录> && ./kepu doctor
   ```
   doctor 报 ✗ 的项先解决。复制 `.env.example` 为 `.env`，请作者自己把 ElevenLabs key 填进去。不要让作者把 key 发到聊天里。
3. **写系列设定**（`series/系列设定.md`）。和作者对话填写，不要替作者编：
   - **观众与承诺**：观众只假设什么基础？看完能做到什么？
   - **分级**：L1 主线、L2 进阶、L3 支线分别对应谁？一期里 L3 占比上限是多少？
   - **严谨契约**：哪些结论在本系列里是黑箱？在第几集打开？
   - **比喻表**：题材里的东西对应画风里的什么？全季固定。原则是：游戏比喻是入口，不是定义。
   - **期目录**：每期写“讲透的一件事”，不写“讲了很多事”。宁可深，不可水。
   - **误解清单**：本系列要纠正的常见误解。
4. **美术方向**：转到 `kepu-studio:art`。

## 新一期（每期都做）

1. 复制 `script/episodes/ep01.md` 的模板，开头填好：
   - 目标时长、本期讲透的一件事、本期问题；
   - 伏笔：从哪期埋下，到哪期回收；
   - 事实与出处、黑箱变化。
2. **先写讲义**：`./kepu notes new` 生成骨架，再按 `kepu-studio:notes` 写定义、定理和误解。稿子里屏幕上出现的定理，从讲义里复制。
3. **事故预演**：写进 `review/epNN_premortem.md`。格式见 studio 技能的 `references/metacognition.md` §1：
   - 本期最可能在哪 5 处翻车；
   - 每处由哪个关卡拦住；
   - 拦不住的，现在就加一个检查。
4. **资料**：
   - 论文和数据放 `research/`。
   - 每个数字、年份、人名都记出处。
   - 能用程序复算的，写 `script/verify_epNN.py`。ETH 用 verify_toys.py 复算了 59 项。
5. 转到 `kepu-studio:script` 写稿。

## 选题的标准（从两部作品学到的）

- **主线**：一句话说清，写成“我们曾经相信 X，为什么信？为什么错？”或者“这个问题为什么回答不了？”。
- **开场钩子**：用一个真实事件、一个悖论或一个反直觉的问题。整个系列的前情只用一分钟回顾。
- **伏笔要回收**：第 1 期埋下的小例子，要在后面的关键时刻回收。例如 ETH 第 1 期的“子句 = 禁止一种取值”，在第 6 期变成子句多项式。
