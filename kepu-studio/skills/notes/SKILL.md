# 讲义、逐字稿、分级

## 分级：两个维度，全系列统一

详细说明见 `references/levels.md`。

| 维度 | 档位 | 视频里 | 讲义里 |
|---|---|---|---|
| 难度 | **L1 主线** | 所有观众都要跟上；只假设高中数学 | 正文 |
| 难度 | **L2 进阶** | 本科理工；精确定义、关键一步 | “进阶”框 |
| 难度 | **L3 硬核支线** | 可以跳过，跳过不影响后面；一期 ≤ 20% | “硬核支线”框（虚线），常常只在讲义里 |
| 严谨度 | **完整 / 骨架 / 黑箱→第 N 集 / 黑箱→文献** | 画面右上角标角标 | 定理旁的徽章，例如 `[完整]` |

**严谨契约**（《地基之下》定的规矩）：
- 视频的角标可以比讲义低，不能比讲义高。
- 讲义的证明如果以骨架引理或黑箱为前提，就标“完整（以引理 X 为前提）”，视频照抄这个前提。
- 屏幕上的定理必须和讲义逐字一致。旁白可以先讲直觉版。

```bash
./kepu stats script/episodes/epNN.md            # 各级时长占比；L1 直接跳到 L3 的地方；没标级的 beat；提问间隔
./kepu stats script/episodes/epNN.md --cut L1   # “主线精简版”：只留 L1 的 beat 清单和时长（剪短视频、做预告用）
```

## 讲义（先写讲义，再写稿子）

```bash
./kepu notes new script/episodes/epNN.md   # → notes/epNN.md：按本期的场景、分级和用到的希腊字母生成骨架
./kepu notes build notes/epNN.md           # → output/epNN/notes.html 和 notes.pdf（需要 Chrome 或 Edge；没有就用浏览器手动打印）
```

**固定结构**：
1. 本期地图：三档目标。
2. 各节：每节都是主线正文，加一个进阶框，加一个硬核支线框。
3. 常见误解和实情。
4. 习题：★ 到 ★★★，难题给提示，答案放在最后。
5. 术语表：中文、英文、读音。多音字和希腊字母的读音写在这里，例如“方差 fāngchā”“σ sigma”。
6. 延伸阅读。

**写法**（来自《地基之下》的讲义规范）：
- **路线 A**：先给具体问题或例子，再抽象，最后回头用抽象工具重新解读这个例子。
- **作者在场**：每节至少有一句直接对读者说的话，比如读法建议、提醒、取舍。
- **引用要诚实**：只写有把握的出处。没把握的章节号、页码、年份不写，只写书名或论文名。历史事实拿不准的，宁可不写。
- 每期对照系列的误解清单自检。

**讲义里的标记**（Markdown，公式交给 KaTeX）：
```
::: thm 定理 2.2（名字）[骨架]          ::: misconception          ::: exercise ★★ 习题 3
……                                       ……                         ……
:::                                      :::                        :::
```
可用的类型：
- `def` `thm` `lem` `prop` `cor` `proof` `example`
- `misconception` `fact`
- `note` `warning`
- `exercise` `hint` `answer`
- `l1` `l2` `l3`
- `blackbox` `recap` `map` `video`

行内可以写 `[L2]`、`[完整]`、`[黑箱 A→12]`、`★`。`<!-- … -->` 里的制作备注不会出现在成品里。
如果想用 LaTeX：《地基之下》用 ctexbook 加 subfiles，B5 开本，每讲 10–20 页。结构照上面那样排即可。

## 逐字稿、分段、字幕

```bash
./kepu transcript script/episodes/epNN.md [--timeline 真实时间.json]
```
生成三样东西：
- `output/epNN/transcript.md`：给读者看的逐字稿。按场景分节，带时间戳，用显示文字（没有替身字和读音标记），带难度和严谨度标签。
- `chapters.txt`：B 站分段和置顶评论里的章节，一行一个，格式是 `00:00 场景名`。
- `epNN.srt`：字幕，按引擎的切分规则切。`2^{o(n)}` 会写成 `2^(o(n))`，不留花括号。

没有 `--timeline` 时，时间按配音时长估计（稿子里会注明“估计”）。成片以后，用渲染出来的时间重做一次：
- anime 引擎：各场景的 `.timeline.json` 加上拼接时的偏移；
- pixel 引擎：`build` 直接输出 `chapters.txt` 和 `.srt`。
