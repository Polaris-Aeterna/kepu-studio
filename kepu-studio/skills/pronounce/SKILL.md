# 读音：多音字和希腊字母，一次定下、永远生效

完整的机制和理由见 `references/policy.md`。最重要的几条：
- **模型按上下文猜多音字，会猜错。** 所以 kepu 不让它猜：每一处有风险的字，在合成前都要有一个决定。决定以后换成只有一个读音的**替身字**（行→航/形，可数→可暑）。字幕照写原字。
- **通用词典（pypinyin）在理工科词上常常是错的**：方差 chà、相变 xiāng、似然 shì、切线 qiè、背包 bēi、用处 chǔ。所以它只用来**发现**风险，不替 A 级字做决定。真正的决定来自三个地方：稿子里的标记、读音词典、上下文规则。
- **分词陷阱**会被拦下来问人。例子：长子句（长子 + 句）、东西藏（东 + 西藏）、宣布了解答（了解）、中间断开（间断）、零处分组（处分）。
- **作者的决定写进文件，以后自动生效。** 决定分三层：
  - 稿子里的 `字〔读音〕`，只管这一处；
  - 项目词典 `pron/lexicon.tsv`；
  - 个人词典 `~/.kepu/lexicon.tsv`，你所有的项目共用。

## 处理 lint 拦下的地方（最常见的任务）

```bash
./kepu lint script/episodes/epNN.md
```
每一处“✗ 未定”都附带原因和一条现成的修法。照下面的顺序选：
1. **改写绕开**：最稳。例子：一模一样 → 完全一样，你得 → 你必须，当成 → 看作。
2. **只这一处念法特殊**：在稿子的读法一侧标 `字〔读音〕`。
3. **这个词以后都这么念**：
   ```bash
   ./kepu lexicon add "长〔cháng〕子句"                  # 只管这个项目
   ./kepu lexicon add "方差〔chā〕" --scope user          # 你所有的项目
   ./kepu lexicon add "分量" --action hold --note "重量 fèn / 分量 fēn"   # 同形词：每次都拦下，要求标读音
   ```
   - **分词陷阱的词条要盖住整个陷阱**：写“非空〔kōng〕子集”，不要只写“非空”。否则引擎还会再拦一次。
   - 动作有三种：`force`（默认，换替身字）、`leave`（只记下决定、不改文字，用于模型肯定念对的常用词）、`hold`（同形词，每次都拦下）。
4. **读音拿不准**：不要猜。给作者做 2–3 个候选的试听，让作者选。以作者为准，不一定是词典读音。例：“当成”作者定念 dāng，词典是 dàng；词典里已经写成 `当〔dāng〕成`。想按词典念的同学，在项目词典里加 `当〔dàng〕成`。

**单句调试**：`./kepu pron "这一行为真，长子句"`。它会显示每个多音字的决定、来源，以及发给模型的文字。

**替身字和拼音兜底**：
- 状态是“~ 拼音”的，说明这个读音没有替身字（děi、mú、qiǎ、zháo、liǎo……），会送带调号的拼音。实测大多念对，但不保证，所以会自动进耳检包。能改写的，先改写。
- 严格模式下，这类地方一律拦下：`kepu.toml` 的 `[pron] strict = true`。

## 希腊字母：英文读音

- **默认**（`[pron] greek = "en"`）：
  - 多音节字母送英文拼写：alpha、sigma、lambda、epsilon……
  - 单音节字母另备能确定念出英文音的写法作为候选：τ→套、ψ→赛、χ→凯、π→派。
- **默认音色已全部验证**（Susan · eleven_v4，作者 2026-10-29 逐个试听）：π→pie、φ→phi、χ→kai、ν→nu、λ→Lambda、τ→套、ψ→赛，其余用英文拼写。
- **φ 有一个提醒**：在“φ 或非 φ”这类逻辑式里，phi 曾经 4/4 念成 fi（《地基之下》第一轮）。所以 φ 每期第一次出现仍然进耳检包。逻辑式里也可以写 `{φ|fài}`。
- **换了音色**：所有字母都按“没验证”处理，第一次出现会进耳检包；要再校准一次。
- **每个音色校准一次**（约 900 字符，花钱，先问）：
  ```bash
  ./kepu greek audition --dry          # 看候选和字符数
  ./kepu greek audition                # 生成 review/greek/index.html：每个字母选最像英文的一条
  ./kepu greek ingest greek_choice.json   # 写进 ~/.kepu/voices/<音色>.json，所有项目共用
  ./kepu greek show                    # 当前每个字母发给模型的写法
  ```
- **大写和小写同名时**，在稿子里说清楚是哪一个：`{Σ|求和}` 或 `{Σ|大写 sigma}`。
- **想要中文课堂读法**（德尔塔、西格玛）：`greek = "zh"`。适合老系列保持前后一致。

## 符号

¬ ∀ ∃ ∈ ≤ ≈ ∞ ⊕ 下标数字等，按 `data/symbols.json` 念成中文。
→ ⊥ ⊢ × ² ^ _ = 这类念法有歧义的符号，读法一侧不许裸写，lint 会拦下，必须写成 `{→|趋于}`、`{x²|x 的平方}` 这样。
阿拉伯数字默认只提醒，最好都写进 `{显示|读法}`。

## 改了规则或词典之后

```bash
./kepu selftest            # 读音引擎的回归测试（真实事故句）必须全过
./kepu lint script/episodes/*.md    # 已经写好的稿子有没有被误伤
```
改动之后，已经合成的句子不会自动重录（缓存按发给模型的文字查找）。`./kepu gate --stage voice` 会列出“配音和当前稿子不一致”的 beat，只重录这些。
