# 写稿：念出来的中文

稿子是**唯一的旁白来源**：配音、字幕、逐字稿、像素分镜的 `s.say`，都从它来。格式速查见 studio 技能的 `references/pipeline.md`，模板是项目里的 `script/episodes/ep01.md`。

## 写之前

- **讲义先写好**（`kepu-studio:notes`）。屏幕上的定理从讲义里复制，旁白可以先讲直觉版。
- 稿子开头写清本期的几件事：
  - 讲透的一件事；
  - 本期问题；
  - 伏笔；
  - 黑箱变化；
  - 事实与出处。

## 写的规矩

1. **念出来的中文**，不是讲义的口语版。
   - 一句不超过 25 字。
   - 一个 beat 15–40 秒。像素引擎里，一段就是一句。
2. **公式要念出来**，并且用 `{显示|读法}` 写。字幕显示左边，配音念右边。
   - `{2ⁿ|二的 n 次方}`、`{x₁|x 一}`、`{3-SAT|三 SAT}`、`{1.308ⁿ|一点三零八的 n 次方}`、`{2026 年|二零二六年}`。
   - 读法超过约 15 个字的式子不要硬念。改成口语描述（“这个比特账”），式子只放在画面上。
   - 读法有歧义时，优先改读法。例：“二的 n 除以二次方”改成“二的二分之 n 次方”。
3. **第一次出现的符号**，要说出它的名字和读法。
4. **希腊字母**：显示写符号，读法写英文名，例如 `{ε|epsilon}`；也可以直接写 ε。引擎会按音色档案念英文（`kepu-studio:pronounce`）。
5. **每 2–3 分钟给观众一个问题**，后面跟 `（停顿 2 秒）`，画面放倒计时或“暂停·思考”。
6. **直觉先于公式**：任何公式出现前，先用一个具体的小例子演示，比如 3 个变量、4 个子句。公式出现后，逐项讲清每一部分对应画面里的什么。
7. **简化要说明**：讲简化版时说清“这里做了简化”。简化可以，错误不行。
8. **结尾固定三件事**：回顾 3–5 句，黑箱清单的变化，下期预告。最后提一句讲义里有完整证明和习题。
9. **难度标签**：
   - L1：所有人都要跟上。
   - L2：本科理工。
   - L3：硬核支线。进入前说一句“这一段可以跳过，不影响后面”。
   - 一期里 L3 ≤ 20%。不要从 L1 直接跳到 L3。
10. **严谨度标签**：`[完整]` `[骨架]` `[黑箱 A→12]` `[黑箱→文献]`。视频里的角标可以比讲义低，不能比讲义高。

## 多音字：写的时候就定下来

- **能改写就改写**：
  - “一模一样”→“完全一样”；“你得先”→“你必须先”；“卡在这里”→“难在这里”；
  - “用不着”→“不需要”；“待会儿”→“等会儿”；“关卡”→“谜题”。
- **改不了就标读音**：`数〔shǔ〕`、`行〔háng〕`。光秃秃一个带引号的字，比如“有没有一种‘数’”，必须标。
- **“行”当“行”讲时**，尽量用规则认得的说法：“第 k 行”“这一行”“每一行”“行和列”。少用“这些行为真”这种和“行为”撞车的句子。

## 写完

```bash
./kepu lint script/episodes/epNN.md        # 必须 0 处拦下；拦下的地方照它给的修法改，见 kepu-studio:pronounce
./kepu stats script/episodes/epNN.md       # 时长、句长、提问间隔、分级分布、太长的 beat
```
然后进入审稿（`kepu-studio:review`）。审稿的修改意见改完后，重新跑这两条命令。

## 分镜（画面说明）

稿子里每个 beat 的“画面：”写这一刻画面上是什么、怎么动，以及动作在说到哪个词时发生。比如“说到‘切一刀’时，红线划过”。
用到具体画风的分镜，单独写在 `script/storyboards/epNN.md`，格式见该目录的 README。改编了稿子里的画面，要写明理由。
