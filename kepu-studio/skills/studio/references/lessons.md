# 经验总结：《地基之下》与《ETH 之墙》两部系列的复盘

两部作品的复盘合在一起，提炼成可复用的原则。每条按“**事 → 根子 → 以后怎么做 → 插件里落在哪**”写。

- **《地基之下》**：中文数理逻辑系列，两季 27 集。
  - 两个版本：像素 RPG 版是主体，另有 Manim 版。
  - 每集配一讲 LaTeX 讲义。
- **《ETH 之墙》**：6 期 × 25–30 分钟的复杂性理论系列。
  - ManimGL 制作，EVA 标题卡画风，另有英文版。
- 两部的配音都用 ElevenLabs eleven_v4，音色 Susan。

## 0. 一页纸结论

1. **能强制就别检测**：
   - 多音字合成前换成只有一个读音的替身字。
   - 符号、希腊字母先写成确定的读法。
   - 合成后再去“听出来”是最贵、最不可靠的办法。
2. **决定写进文件，不靠记忆**：读音、配色、措辞、黑箱状态，作者定一次，写进词典或设定文件，以后自动生效。
3. **检查器先验坏例子**：
   - whisper 把念错的 φ 也写成 “φ”，验收形同虚设。
   - 新检查器上线前，先喂已知的坏样本。
4. **作者的耳朵和眼睛定标准**：先给 5–6 个候选的试听或样张，作者选定后再批量做。
5. **一张表的关卡**：脚本、配音、画面、发布四个阶段，每个阶段都用机器检查给 ✓/✗；有 ✗ 就不往下走。
6. **先手工做完一个范例，再并行铺开**。
7. **花钱的、对外的操作先估算、先问**。

## 一、读音（返工最多的地方）

### 1. 模型按上下文猜多音字，而且会猜错
- **事**：
  - 《地基之下》：“无穷多行”念成 xíng；表格多的集里，“就行了”也被念成 háng。
  - 其他念错过的：可数（kěshǔ）、奇偶（jī）、对称（chèn）、一模一样（mú）、当成。
  - 《ETH》：“长子句”被念成 zhǎng 子句。模型把它切成“长子 + 句”，这是分词陷阱。
  - 第五轮全量审计：两季 2805 句，查出 537 处有风险。最多的是“数”301 处、“当”29 处、“模”28 处、“空”21 处、“得”19 处、“长”17 处。
- **根子**：
  - 拿不准的字交给模型猜。
  - 词规则只覆盖“已经出过事的字”，新搭配一出现就漏。
  - 规则散在 4 个文件里，两个项目各抄一份，抄着抄着就不一样了。
- **以后怎么做**：
  - 每个有风险的多音字，合成前都必须**有决定**。来源有三种：稿子里的标记、词典、规则。
  - 没决定的句子**拦下不合成**。
  - 决定后换成替身字，字幕照写原字。
  - 词典分三层：插件内置、个人全局、项目。一个词定一次，以后所有项目自动生效。
- **插件**：`kepu lint`、`kepu pron`、`kepu lexicon add`。
  - 多音字分 A、B 两级。
  - 分词歧义检测（ambiguity）专门抓“长子句、可数学家、一只有、能量出”这一类陷阱。

### 2. 词典读音也会错，而且错得很自信
- **事**：拿 pypinyin 试 STEM 词。下面这些都错了：
  - 方差 → chà，应为 chā
  - 相变 → xiāng，应为 xiàng
  - 似然 → shì，应为 sì
  - 切线 → qiè，应为 qiē
  - 泊松 → pō，应为 bó
  - 重积分 → zhòng，应为 chóng
  - 第三行 → xíng，应为 háng
  - 定义为零 → wèi，应为 wéi
- **根子**：通用词典不认识领域词，同形词（分量 fèn/fēn、倒数 dàoshù/dàoshǔ）它只能挑一个。
- **以后**：
  - 词典（G2P）只用来**发现风险**，不能自己替 A 级字做决定。
  - 领域词靠人工校过的内置词典。
  - 同形词一律拦下，要求在稿子里标读音。
- **插件**：`data/lexicon.tsv` 的内置 STEM、游戏、人名词条；`hold` 词条；A 级字。

### 3. 强制也会把错误固化
- **事**：
  - 替身字“档”被念成 dǎng，“储”被念成 chú，都是台湾读音。
  - 词规则“可数 → 可暑”误伤了“可数学家”。
- **根子**：强制是确定的，所以规则一旦判错，就**一定**念错。
- **以后**：
  - 替身字必须两岸同音，新替身字第一次使用时进耳检包。
  - 词条用最长匹配；不同词条冲突时，或者规则和词典冲突时，**拦下问人**，不自己猜。
- **插件**：
  - `standins.tsv` 标出每个替身字是“实战验证”还是“新”。
  - 耳检包自动收录新替身字。
  - 冲突检测的结果是 HOLD。

### 4. 希腊字母：拉丁拼写念不稳，中文音译又不是英文
- **事**：
  - 原样送进去：φ 念成“非”，ψ 念成 fei、pi，或者被吞掉，Γ 念成 ge，σ 念成 sick，⊥ 念成 perp。
  - φ 前后试了好几种：phi 4/4 念成 fi；fye 作者否了；fài 6/6 念对。
  - ψ 最后定为汉字“赛”，ε 作者选了英文 epsilon。
- **根子**：
  - 拼写稳不稳，取决于具体的音色和模型。
  - 一直按字母逐个临时决定，没有一张经过校准的表。
- **以后**：
  - 默认读**英文**：多音节字母用英文拼写；单音节字母另备能确定念出英文音的汉字或拼音作为候选（τ→套、ψ→赛）。
  - 2026-10-29 作者在 Susan 上逐个试听，定下：π→pie、φ→phi、χ→kai、ν→nu、λ→Lambda、τ→套、ψ→赛，其余用英文拼写。φ 在“φ 或非 φ”这类逻辑式里曾经念成 fi，所以每期第一次出现仍然进耳检包。
  - 多音节的字母用英文拼写。
  - **每个音色只校准一次**：一次试听，给每个字母 2–3 个候选，作者选定后写进音色档案，以后所有项目共用。
- **插件**：
  - `data/greek.json`
  - `kepu greek audition`：生成试听页，作者勾选。
  - 结果存进 `~/.kepu/voices/<音色>.json`。

### 5. ASR 验收不了读音；全片人耳复听又太贵
- **事**：
  - whisper 会把念错的字按上下文“纠正”回来。
  - 最小对立对的声学比较，在边界上噪声很大：换一个替身字，结论就翻过来。
- **以后**：
  - 合成后只听**高风险点**：拼音兜底、希腊字母、新替身字、冲突处、外文名首次出现，再加 5 处随机抽查。
  - 用逐字时间戳切出 2–3 秒的片段，作者 2 分钟听完。
  - 结果写回词典和音色档案。
- **插件**：`kepu earcheck build / ingest`，生成可点击的试听页。

### 6. 作者的决定不一定是词典读音；改之前先确认是哪一处
- **事**：第 8 集里，“一直数下去”要念 shǔ，“有没有一种‘数’”要念 shù，同一句里两个“数”读音不同。小号按词典定了，而且先改错了一处。
- **以后**：
  - 作者报“X 读错了”，先确认**集、时间、整句、哪一个字、应该念什么**，再动手。
  - 改完给作者一段新旧对照的试听。
- **插件**：`/kepu-studio:fix` 流程。

## 二、画面

### 7. 架构性的约束要写成规则、做成自动检查
- **事**：
  - 像素版的对话框最后画，y > 134 的东西都会被盖住。作者在第 2 集 7:14 发现一处，全量一查，两季有几百处候选。
  - ETH 版也有字幕区压字、出框、标签被线盖住的问题。
- **以后**：
  - 引擎的隐含规则写进引擎说明：内容区、字幕区、细字层在上、标签高度。
  - 渲染前必须过遮挡、出框检查和联系表。
  - 有意的叠放进白名单。
- **插件**：
  - 两套引擎模板自带这些检查。
  - `kepu gate --stage picture`。

### 8. 字形与排版陷阱
- `·`（U+00B7）会被当成中文间隔号，占一个全角宽；“✗”没有字形；数字“1”看起来像“I”。
- ManimGL 1.7.2 的坑：Noto CJK 会坏字；Pango 忽略正值的 rise，上标不升；`MarkupText` 直接用会报错。
- 字幕切分：
  - 旧规则会切进引号、公式、词的中间，出现只有“…”的条、不足 1.2 秒的碎片。
  - 统一的 DP 切分器上线后：碎片 91 → 0，拆开的引号 70 → 0，切进词内 6 → 0。
- **插件**：字幕切分器（`kepu subs`）和引擎模板里已经修好。

### 9. 画风：从题材里长出来，不是贴皮
- 《ETH》用 taste-skill 做了 6 个方向的概念帧：纪念碑谷、Mini Metro、女神异闻录 5、EVA、NieR、空洞骑士。作者选定 EVA。
- EVA 落地成一套系统：
  - 黑底，暖白墨。
  - 红色是唯一的“判定色”，每屏最多一处。
  - 签名动作是“判定线”，每期 ≤ 3 次。
  - 大字卡每期 ≤ 8 次、插卡 ≤ 6 次，两次之间至少隔 20 秒。
- 《地基之下》像素 RPG：
  - 黑箱是宝箱，定理是道具说明窗，误解卡红色、实情卡绿色，严谨度角标放右上。
  - 全季的游戏比喻表固定不变。
  - 原则：“游戏比喻是入口，不是定义”。
- **竞品测试**：把 IDEA 句子里的题材换成别的科普题目，句子仍然成立，说明这只是一层皮。
- **插件**：`kepu-art-direction` 技能，包括概念帧、评委打分、风格圣经、节奏预算。

### 10. 长片的可持续性
- 3 小时的 EVA 风有压迫感，所以内建四种“时刻”轮换，引擎负责计数并报警：内容时刻、大字、插卡、白底段落。
- 高饱和的大色场只留给标题、定理、反转这些时刻。

## 三、内容与教学

### 11. 事实要能追溯；数字要用代码复算
- 《ETH》审稿发现了 7 条 🔴 必改：
  - 日期：“同一个星期”，实际差 9 天。
  - 四舍五入制造出“进展”：1.308 → 1.307，其实 1.30704 一直没变。
  - pdftotext 把 4/9 读成“49”。
  - 编辑距离被列为倒下的结论，其实它建立在 OV 假说上，幸存了下来。
- 好做法：
  - `verify_toys.py` 把全部玩具例子复算一遍：59 项 PASS。
  - 独立的事实核查要给出处。
- **插件**：
  - 事实账本（每个数字、年份、人名都要有出处或复算脚本）。
  - `kepu-fact-checker` 子 agent。

### 12. 严谨契约：视频角标不得高于讲义
- 《地基之下》把证明分成【完整】【骨架】【黑箱 A→12】【黑箱→文献】四档。视频角标可以比讲义低，不能比讲义高。
- 屏幕上的定理与讲义逐字一致；旁白可以先讲直觉版。
- 每集对照《常见误解》清单自检。封面文字不能说出本集要纠正的误解。
- **插件**：
  - 脚本里的严谨度标签。
  - 讲义模板里的严谨度、误解卡、实情卡。
  - `kepu levels` 统计。

### 13. 讲义先行，稿子是“念出来的中文”
- 先写讲义，再写稿子，屏幕文字从讲义里复制。
- 稿子的规矩：
  - 每句 ≤ 25 字。
  - 公式要念出来，第一次出现的符号要说出名字。
  - 每 2–3 分钟给观众一个问题，配停顿。
  - 结尾固定三件事：回顾、黑箱清单的变化、下集预告。
- 节奏：中文约 220–270 字/分钟；ETH 按 4.5 字/秒估时，单个 beat 15–40 秒。
- **插件**：
  - 脚本格式支持停顿标记 `（停顿 2 秒）`。
  - `kepu stats` 查句长、提问间隔、beat 时长。

## 四、流程与工程

### 14. 一张表的关卡
- 检查散在各处、靠记忆串起来，“做完了吗”就没有统一答案。
- 《地基之下》的 `gate.py` 把 script / voice / picture / release 四个阶段排成一张表，有 ✗ 就退出码 1。
- **插件**：`kepu gate`。

### 15. 用“看得见的事实”判断状态
- “重做过没有”看文件的修改时间、大小和缓存键，不看“我记得”。
- **插件**：
  - gate 用缓存键检测“稿子改了，录音还是旧的”。
  - release 阶段比较成片和分镜的新旧。

### 16. 缓存和幂等
- 每一条录音合成完立刻存盘：缓存键 = 发给模型的文字 + 音色参数。只有改过的句子才重新花钱。
- 不要改缓存命名用到的代码（例如 `voice()`），否则整季缓存失效。
- 步骤要能重复运行：依赖的中间文件不在，就跳过并说明，而不是整步失败。
- 项目没有 git 的话，大改之前先打包备份。

### 17. 成本与额度
- 一集（25–30 分钟）约 4–5 千字符。额度每月重置。账单有延迟，而且不是 1:1，所以按“发出的字符”做预算。
- 默认一次最多发 2000 字符（`--max-chars`）。超过就拒绝，先问。
- 余额不要低于 10,000：账户是两个项目共用的。
- eleven_v4 turbo 半价；一期之内不要混用模型。
- **插件**：`kepu voice --dry` 估算、`--max-chars` 设上限、`kepu quota` 查余额。

### 18. 机器负载与并行
- 7 个渲染同时跑，10 核机器的负载到 200，电脑卡死。默认两集两集地渲染。
- 多个 agent 并行时：每个只写自己那一集的文件夹；共享引擎只由“引擎作者”改，而且必须向后兼容；临时文件名带集号前缀。
- 先手工做完一个范例，写进分派说明，再派给 6 个 agent，风格和质量就一致。
- 分派说明要自包含：背景、规则、工具、禁止事项、范例、汇报格式。

### 19. 英文版 / 多版本
- 两个版本共用一份录音（像素版和 Manim 版），或者共用一套分镜（中文版和英文版），可以大幅省钱。
- 改引擎时，用逐像素哈希证明“中文版不变”，这是向后兼容的硬证据。

## 五、沟通

### 20. 报告要可核对
- 读音问题给带编号的试听剪辑，画面问题给联系表，进度汇报给完成时间的估计。
- 作者用中文写，回复也用中文。
- 不替作者发布：发布文件夹准备好，上传由作者自己做。

## 六、元认知：这套流程怎么“自我升级”

每期做完跑一次 `/kepu-studio:retro`：
1. 收集这一期的事故：耳检的 ✗、审稿的 🔴、渲染警告、返工次数和花费。
2. 每个事故问到根子：为什么没被更早的关卡拦住？
3. 修系统，不修个例：加词条、规则、检查、模板约束，并补一个回归测试。
4. 把“事 → 根子 → 以后”追加到项目的 `LESSONS.md`。值得分享给同学的，导出成词典补丁。

这份文件本身就是这样长出来的：每一条背后都是至少一轮返工。
