- 目标时长：约 20 分钟（念 4500–5500 字，按 260 字/分钟）
- **本期讲透的一件事**：……
- **本期问题**（开场抛出、结尾回答）：……
- **伏笔**：〔伏笔 A〕……→ 第 N 期回收
- **事实与出处**：每个数字、年份、人名都要有出处，或者有复算脚本（`script/verify_*.py`）
- **黑箱**：本期引入……；本期打开……

写法速查：
- `{显示|读法}`：字幕显示左边，配音念右边。数字、公式、上下标、缩写都这样写，例如 `{2ⁿ|二的 n 次方}`、`{3-SAT|三 SAT}`。
- `字〔读音〕`：只管它前面那一个字，例如 `数〔shǔ〕`、`行〔háng〕`。也可以写成 `数〔shu3〕`。
- 希腊字母：显示写符号，读法写英文名，例如 `{ε|epsilon}`。也可以直接写 ε，引擎会按音色档案念英文。
- `（停顿 2 秒）`：停顿，不念出来，合成后会插进静音。
- 标签：beat 标题后面写难度 `[L1]` / `[L2]` / `[L3]`，以及严谨度 `[完整]` / `[骨架]` / `[黑箱 A→3]`。
