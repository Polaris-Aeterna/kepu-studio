# 分镜

分镜写在 `script/storyboards/epNN.md`，每期一份。台词以稿子为准，分镜只规定镜头。

## 文件开头写清三件事

- **本期 IDEA**：在这一期里，[题材自己的东西] 变成 [画风特有的视觉装置]。
- **节奏预算**：写明本期计划用多少次，并保证不超过系列设定里的上限。
  - 大字卡、插卡各几次；
  - 签名动作几次；
  - 镜头推拉几次；
  - 白底（换气）段落几段。
- **时刻清单**：按顺序列出每一个大字卡和插卡的文案。

## 每个 beat 一行

例子：

```
- 07 【内】三条规则依次入场，左对齐锚线。强调色：无。对应：同。
```

- **卡型**：
  - 【章】章节卡（不计数）
  - 【大】大字卡
  - 【插】插卡
  - 【内】内容图
  - 【混】大字和内容同屏
  - 【白】白底段落
  - 【判】签名动作
- **强调色**：写明这一屏唯一的强调色落在哪里。没有就写“无”。
- **对应**：
  - “同”表示照稿子的“画面”做；
  - “改”表示改编了，要写明理由。

## 检查

- **相邻构图**：相邻两个 beat 不用同一种构图。依次换着来，比如公式居中 → 左文右图 → 表格 → 满屏图。
- **画面跟词走**：画面上的变化发生在说到那个词的时刻，而不是这段台词的开头。
- **不压字**：文字正在被念的时候，不要有东西从它上面经过。
