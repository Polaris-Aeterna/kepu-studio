# 《{{NAME}}》系列设定（系列圣经）

这一份写清楚“全系列不变的东西”。每一期的稿子、分镜、讲义都以它为准。改动它要写日期和理由。

## 1. 观众与承诺
- **观众**：例如理工科本科生和程序员，只假设高中数学（讲义可以略高）。
- **一句话承诺**：看完这个系列，观众能做到什么、真正懂了什么。
- **对标**：例如 3Blue1Brown、Veritasium 的水准。这不是“PPT 配念稿”。

## 2. 分级（两个维度，全系列统一）
| 维度 | 档位 | 含义 | 在哪里标 |
|---|---|---|---|
| 难度 | L1 主线 | 所有观众都要跟上；只用高中数学 | 稿子：beat 标题后写 `[L1]` |
| 难度 | L2 进阶 | 本科理工能跟上；精确定义、关键一步 | `[L2]` |
| 难度 | L3 硬核支线 | 可以跳过，跳过不影响后面；视频里说一句“这一段可以跳过” | `[L3]`，一期占比 ≤ 20% |
| 严谨度 | 完整 / 骨架 / 黑箱→第 N 集 / 黑箱→文献 | 视频角标可以比讲义低，不能比讲义高 | 稿子 `[骨架]`，画面右上角标 |

## 4. 美术方向（由 `kepu-studio:art` 定，选定后照抄到这里）
- **画风**：例如 EVA 标题卡、像素 RPG、女神异闻录式 UI……
- **IDEA 句**：“在这个系列里，[题材自己的东西] 变成 [画风特有的视觉装置]。”要过竞品测试：把题材换掉，句子就不成立。
- **配色 token**：BG / SURFACE / INK / MUTED / ACCENT（强调色每屏最多一处）。
- **字体**：展示用一种，正文用一种；三档字号。
- **签名动作**：每期最多 3 次，例如判定线、斜切转场。
- **节奏预算**：大字卡 ≤ 8、插卡 ≤ 6，两次之间至少 20 秒；冷开场 3 分钟内可以多用。
- **字幕**：字幕是画面的一部分，字体和颜色属于这个画风。

## 5. 配音
- 音色、模型、语速写在 `kepu.toml` 的 `[voice]`。
- 希腊字母读英文。每个音色用 `./kepu greek audition` 校准一次。
- 读音约定（作者的偏好，例如“当成念 dāng”）写进 `pron/lexicon.tsv`，并在这里列一行。

## 6. 每期固定结构
1. 冷开场：1 分钟钩子，加上本期问题。
2. 正文：每 2–3 分钟给观众一个问题，配（停顿 2 秒）。
3. 结尾：回顾 3–5 句，黑箱清单的变化，下期预告。
4. 最后一句提醒：讲义里有完整证明和习题。
